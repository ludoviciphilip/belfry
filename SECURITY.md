# Security Policy

## Supported versions

Only the latest released version of Belfry is supported with security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities. Instead, use GitHub's private reporting:

[Report a vulnerability](https://github.com/ludoviciphilip/belfry/security/advisories/new)

This opens a private advisory visible only to the maintainer, so details can be discussed and fixed before anything is public.

If your finding concerns the EasyTier engine itself (shipped unmodified by Belfry), please also report it to the [EasyTier project](https://github.com/EasyTier/EasyTier/security).
